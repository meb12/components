# PO UI Components

Projeto desenvolvido em Angular como parte de um teste técnico de Front-end.

## Componentes

- **Select:** componente de seleção de opções, com suporte a `ngModel` e Reactive Forms.
- **Switch:** componente de alternância entre `true` e `false`, também compatível com formulários Angular.

Ambos permitem controlar o estado desabilitado.

## Tecnologias

- Angular
- TypeScript
- HTML
- CSS
